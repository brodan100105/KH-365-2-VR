# Settings

Generated by `khvr_settings_doc` from `core/src/settings.cpp`; do not edit by hand.

Every option is on the in-headset VR panel (hold the left **Menu** button) and in
`/sdcard/Android/data/com.khdays.vr/files/khvr.ini`, which the app rewrites when you
close the panel. Each tab is an INI section; values out of range are clamped.
